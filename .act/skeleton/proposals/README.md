One file per proposed change, named `YYYY-MM-DD-<slug>.md`, with a frontmatter header naming its
author, date, and target (`rules`, `coding`, `checklists`, or `config`):

```
---
author: <who>
date: YYYY-MM-DD
target: rules
---

# Title
```

Older proposals with the same fields as plain lines (no `---`) are read just the same. Anyone may
add a proposal here, but only the owner integrates it and moves it to
`docs/ai/work/archive/proposals/` — accepted and rejected alike, keeping the header form it has.
