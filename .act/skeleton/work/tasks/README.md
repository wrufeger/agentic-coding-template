One task per file, `YYYY-MM-DD-<slug>.md`, created with `python .act/scripts/entries.py new task
<title>`. The header carries the assigned `id: T<n>` once one exists (`docs/ai/config.md` §
`mode` decides when — see `docs/ai/work/README.md`); the body states the goal and the check
criteria. Read by `.act/scripts/board.py` for the board; moved to `docs/ai/work/archive/` once
accepted (`docs/ai/work/archive/README.md`).
