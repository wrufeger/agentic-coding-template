# Architekturentscheidungen (ADRs) — {{PROJEKTNAME}}

**ADR** steht für *Architecture Decision Record* — ein kurzer Eintrag je Entscheidung: was entschieden wurde,
welche Alternativen verworfen wurden und was daraus folgt. Zitiert wird er als `ADR-<n>`.

Fortlaufend nummeriert, nie umnummerieren. Vor neuen Features hier nachschauen, damit keine bereits getroffene
Entscheidung stillschweigend revidiert wird. Eine überholte Entscheidung wird **nicht gelöscht**, sondern im
Eintrag als überholt markiert, mit Verweis auf den ADR, der sie ablöst — sonst ist später nicht mehr
nachvollziehbar, warum der Code aussieht, wie er aussieht.
